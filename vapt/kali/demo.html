Notes for the report

What to know about this run

  • The hardened build's login limit (10 per minute per IP) stopped the test scripts' own logins. The scripts now wait out the limit and retry once. No application code changed.
  • Checks F05 and F06 were answered by that rate limit (HTTP 429) before the account lockout. live_attack.py tests the lockout itself and gets the 401 lockout response.
  • OWASP ZAP is not installed on the Kali VM and the lab has no internet, so nikto covers the header and configuration scan.
  • The browser demo was driven in Firefox on Kali. Burp Suite screenshots are still yours to take if your guide wants them.
